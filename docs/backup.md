# الباك اب التلقائي

كل يوم الساعة 1 الظهر، أو أول ما الجهاز يفتح بعد كده، السكريبت بياخد نسخة من الداتابيز وملفات Supabase، ويشفرها، ويحفظها في `E:\beshola-backup` وفي ريبو خاص على GitHub اسمه `beshola-backups`. بيقرأ من الموقع بس، ومش بيغير فيه حاجة.

## اللي بيتحفظ
- **الداتابيز:** الجداول `public` و`auth` و`storage`، يعني الحسابات والحجوزات والمرضى وبيانات النمو. آخر 30 نسخة بس.
- **الملفات:** اللوجوهات والأشعة. بينزل الجديد والمتغير بس، عشان الباقة المجانية فيها 5 GB نقل في الشهر. الملف اللي يتمسح من Supabase بيفضل في الباك اب 30 يوم.
- **ما بيتحفظش:** باسوردات الـEdge Functions (Secrets)، ومهام `pg_cron`، والكود نفسه لأنه على GitHub.

كل حاجة متشفرة بـAES-256، وأسماء الملفات متغيرة، عشان المسارات الأصلية فيها أرقام مرضى.

## التسطيب
مفيش أي برنامج بيتسطب، فمفيش تأثير على أي مشروع تاني على الجهاز.

1. **أدوات PostgreSQL:** نسخة ZIP بدون تسطيب، بنفس نسخة Supabase أو أحدث (Supabase دلوقتي على 17). نزّلها من [صفحة EDB](https://www.enterprisedb.com/download-postgresql-binaries) وفكها بحيث يبقى عندك `E:\beshola-tools\pgsql\bin\pg_dump.exe`.
2. **GitHub:** لازم `gh` يكون مسجل دخول على الجهاز، والريبو الخاص `momenesam11/beshola-backups` فيه Release اسمه `db` وواحد اسمه `files`.
3. `npm run backup:setup` وجاوب على الأسئلة. البيانات بتتحفظ في `.env.backup` على جهازك بس، وGit بيتجاهله.
4. **احفظ عبارة التشفير** اللي هتظهر في مكان برة الجهاز. من غيرها النسخ مستحيل تتفتح.
5. `npm run backup` لأول نسخة.
6. `npm run backup:verify` لتجربة الاسترجاع. بتعمل داتابيز مؤقتة على جهازك وترجّع فيها النسخة وتقارن عدد الصفوف، وبعدها تمسحها. مش بتلمس الموقع.
7. `npm run backup:schedule` عشان تشتغل كل يوم.

## المتابعة
- **`LAST_STATUS.txt`** في `E:\beshola-backup`: أول كلمة فيه `OK` أو `FAILED` ومعاها التاريخ.
- **`backup.log`:** سجل كل المرات، من غير أي بيانات عملاء.
- لو النسخة فشلت، بتظهر رسالة على الشاشة.
- كرر `npm run backup:verify` مرة كل شهر تقريبًا.

## الاسترجاع
**ما ترجعش نسخة على الموقع الشغال.** أي استرجاع بيبدأ على مشروع Supabase جديد فاضي، وبعد ما البيانات تتراجع نحول الموقع عليه. اطلب من Claude يعملها معاك خطوة خطوة، لأنها بتختلف حسب اللي حصل.

## اللي ممكن يفوت
لو الجهاز مقفول أيام، مفيش نسخ في الأيام دي. وأي بيانات اتكتبت بعد آخر نسخة بتضيع لو حصلت مشكلة قبل النسخة الجاية. Supabase Pro بيحل جزء من ده بنسخة يومية من عندهم.
